**Q4.** What is Python's foundational data visualization library, a powerful and flexible system for publication-quality plots?

* Pandas
* Matplotlib
* Seaborn
* NumPy

<details>

<summary>Show hint</summary>

* **Where:** [Matplotlib](../3.2-matplotlib/).
* **Think:** Pandas and NumPy are data libraries (with thin plotting wrappers). Of the two real plotting libraries, one is built **on top of** the other, the foundational one is the **lower** layer.

</details>

**Q5.** What is the innermost part of a Matplotlib plot?

* Axes
* Plot Area
* Figure
* Grid

<details>

<summary>Show hint</summary>

* **Where:** [Matplotlib](../3.2-matplotlib/), anatomy of a figure.
* **Think:** Matplotlib nests components: outermost is the canvas (Figure), then the coordinate system (Axes), then the region where data is actually drawn. The innermost is where the **points/lines** land.

</details>
