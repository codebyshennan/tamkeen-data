# Custom 404 Page — Data Science Themed

## Overview

A custom 404 page for the Tamkeen Data Science & AI course site that uses a "missing data" theme (`NaN` / `None`) to stay on-brand with the curriculum. GitHub Pages automatically serves `404.html` from the repo root.

## Design

### Hero

- Large `NaN` as the primary visual element (styled similarly to the home hero)
- Subtitle: **"This page returned None"**
- Small decorative code snippet: `pd.isna(this_page)  # True`

### Navigation / Recovery

Three action links styled as cards (reusing timeline-card patterns):

1. **Home** — links to site root
2. **Curriculum** — links to `curriculum.md`
3. **Search** — triggers Pagefind search overlay or links to homepage with search focus

### Technical Details

- **File**: `docs/404.html` (Jekyll front matter with `permalink: /404.html`)
- **Layout**: Uses the existing `default` layout (site header, theme toggle, footer)
- **Styling**: Inline `<style>` block in the page (scoped to `.error-page`), using existing CSS custom properties (`--text`, `--text-muted`, `--link`, `--bg-card`, `--border`, etc.)
- **Dark/light mode**: Fully compatible via existing CSS variables
- **Responsive**: Flexbox card layout wraps on mobile
- **No JS required**: Pure HTML/CSS beyond what the layout already provides

### Content

```
NaN
This page returned None

>>> pd.isna(this_page)
True

The page you're looking for doesn't exist or has been moved.

[Home]  [Curriculum]  [Search]
```

### Constraints

- No external dependencies beyond what the site already loads
- Must work on GitHub Pages (static, no server-side logic)
- Should feel like a natural part of the site, not a novelty page
